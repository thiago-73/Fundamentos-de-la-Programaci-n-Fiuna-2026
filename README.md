
# 📘 Repositorio Académico – Fundamentos de la Programación

## 🎯 Descripción General

Este repositorio ha sido desarrollado con el objetivo de documentar de forma organizada, clara y progresiva todos los trabajos realizados en la asignatura **Fundamentos de la Programación**, correspondiente a la formación en ingeniería.

Aquí se almacena el registro completo de:

- 📌 Tareas académicas
- 🧪 Talleres prácticos
- 📝 Evaluaciones y exámenes de práctica
- 📂 Ejercicios propuestos por la cátedra
- 📈 Estudios y prácticas personales de refuerzo
- 💻 Proyectos de programas desarrollados durante el curso

El trabajo se centra principalmente en el lenguaje **Python**, utilizando herramientas fundamentales como **NumPy** para el cálculo numérico, manejo de matrices y análisis de datos.
De manera complementaria, se emplea **MATLAB** para simulaciones, modelado matemático y resolución de problemas computacionales cuando la materia lo requiere.

---

## 🎯 Objetivos del Repositorio

- ✅ Desarrollar una base sólida en programación estructurada y lógica computacional
- ✅ Aplicar conceptos matemáticos mediante programación
- ✅ Fortalecer el uso de Python para resolución de problemas reales
- ✅ Aprender el uso práctico de librerías científicas como NumPy
- ✅ Introducir el análisis computacional con MATLAB
- ✅ Mantener un historial académico organizado y accesible
- ✅ Fomentar buenas prácticas de programación y documentación

---

## 🚀 Propósito Académico

Este repositorio no solo funciona como almacenamiento de trabajos, sino como una herramienta activa de aprendizaje, mejora continua y crecimiento académico.
Refleja la evolución progresiva en programación, desde ejercicios básicos hasta proyectos más complejos.

Además, servirá como referencia futura en materias avanzadas relacionadas con:

- 📊 Análisis de datos
- 🤖 Inteligencia artificial
- ⚙️ Ingeniería computacional
- 📐 Modelado matemático
