
# 📘 Fundamentos de la Programación

## 📚 Descripción General

Este repositorio documenta de manera organizada y progresiva todos los trabajos realizados en la asignatura **Fundamentos de la Programación**, correspondiente a la formación en ingeniería.

Incluye el registro de:

* 📌 Tareas académicas
* 🧪 Talleres prácticos
* 📝 Evaluaciones y exámenes
* 📂 Ejercicios propuestos por la cátedra
* 📈 Estudios y prácticas personales de refuerzo
* 💻 Proyectos de programas desarrollados durante el curso

El enfoque principal está en el lenguaje de programación **Python**, utilizando herramientas fundamentales como:

* 🔢 **NumPy** para cálculo numérico y manejo de matrices
* 📊 **Matplotlib** para visualización de datos y análisis gráfico

De manera complementaria, se emplea **MATLAB** como plataforma de apoyo para simulaciones, modelado matemático y resolución de problemas computacionales cuando la materia lo requiera.

---

## 🎯 Objetivos

* Desarrollar una base sólida en lógica de programación
* Aplicar programación a problemas matemáticos y técnicos
* Fortalecer el dominio de Python
* Aprender el uso de librerías científicas como NumPy y Matplotlib
* Introducir herramientas de análisis como MATLAB
* Mantener un historial académico organizado
* Fomentar buenas prácticas de programación y documentación

---

## 🚀 Propósito Académico

Este repositorio funciona como una herramienta de aprendizaje continuo y portafolio académico, reflejando la evolución en programación desde conceptos básicos hasta proyectos más avanzados.

Será una base importante para materias futuras relacionadas con análisis de datos, inteligencia artificial, ingeniería computacional y modelado matemático.
